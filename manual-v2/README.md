# Star Rod Classic User Guide

This guide covers Star Rod Classic 0.5.9 projects targeting Paper Mario (US v1.0).

The manual is divided into three parts. The introduction explains Star Rod and the parts of Paper Mario it works with. The guides walk through particular tasks. The reference collects exact syntax, commands, flags, limits, and other details you may need to look up while working.
