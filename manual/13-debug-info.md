# 13. Debug Info

**Enable Debug Information** can be enabled in the mod options or `mod.cfg`. This installs Star Rod's debug patch and shows the player position and map or battle name at the bottom of the screen. The following controls toggle its additional displays and cheats:

- DPAD LEFT - show debug options; use L (cancel), R (accept), and DPAD to navigate
- DPAD RIGHT - show watched values (set in Mod Manager) and heap memory usage
- DPAD DOWN - toggle god mode; deal 99 damage in battle and take no damage from most attacks
- DPAD UP - toggle turbo mode; use faster walk and run speeds and bypass enemy encounter triggering
