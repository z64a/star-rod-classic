Bundled Java runtime
--------------------

Star Rod releases include a reduced Java runtime. Its module licenses and
third-party notices are preserved in runtime/legal/.

Contributed patches
-------------------

Optional patches under contributed/ retain their license files beside the
corresponding patch files.
