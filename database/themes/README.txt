Star Rod can use custom themes desgined for IntelliJ.
You can browse a collection of themes here:

https://plugins.jetbrains.com/search?tags=Theme

Find a theme you like and download it as a JAR file.
Place the JAR in this folder and the custom theme will show
up in the theme editor next time you run Star Rod.

Themes created with Star Rod's Theme Designer use the
*.starrod-theme.json format. These files contain a bundled
base theme and only the properties changed by the user.
Copy one into this folder to install a shared theme.
